# PvP Essential

마인크래프트 멀티플레이 서버용 PvP 규칙 데이터팩입니다. 플러그인 없이 **바닐라 데이터팩만으로** 동작합니다.

- 지원 버전: **1.21.11 ~ 26.2 이상** (이후 버전도 자동 지원되도록 설계)
- 실제 서버 테스트 완료: **1.21.11 / 26.1 / 26.2**

---

## 적용되는 규칙

| 규칙 | 내용 |
|---|---|
| 엔더 진주 제한 | 인벤토리에 최대 **16개**(1세트). 초과분은 자동 제거 |
| 불사의 토템 제한 | 인벤토리에 최대 **2개**. 초과분은 자동 제거 |
| 철퇴 내려찍기 쿨타임 | 내려찍기(smash) 명중 후 **30초** 동안 내려찍기 불가 (일반 근접 공격은 그대로) |
| 창 lunge 쿨타임 | lunge 발동 후 **10초** 동안 lunge 불가 (창 자체는 계속 사용 가능) |
| 엔더 크리스탈 폭발 | 플레이어가 받는 피해 **0** (넉백은 유지). TNT·크리퍼는 영향 없음 |
| 리스폰 정박기 폭발 | 플레이어가 받는 피해 **0** (넉백은 유지) |
| 전투 중 겉날개 금지 | 전투 중에는 활공 불가, 활공 중이면 즉시 해제 |
| 전투 중 급류 삼지창 금지 | 전투 중에는 급류(Riptide) 인챈트가 일시 제거됨 |
| 전투 중 로그아웃 | 전투 중 접속 종료 시 **재접속하는 순간 사망** |
| 황금 사과 대량 제작 | 금 블록 8 + 황금 사과 1 → **황금 사과 32개** |
| PvP 장비 상자 | 다이아 블록 9개 → 풀장비가 들어 있는 상자 1개 |

### 전투 상태(전투 중)의 정의

플레이어가 **다른 플레이어에게 피해를 주거나 받은 시점부터 10초**입니다.
때린 쪽도 함께 전투 상태가 되므로, 한 대 치고 겉날개로 도망가거나 접속을 끊는 행동이 모두 막힙니다.
몹·낙하·용암 등 PvP 가 아닌 피해는 전투 상태가 되지 않습니다.

화면 하단 액션바에 남은 전투 시간과 철퇴/창 쿨타임이 표시됩니다.

### PvP 장비 상자 레시피 (다이아몬드 블록 9개)

3×3 을 전부 다이아몬드 블록으로 채우면 다음이 들어 있는 상자가 나옵니다. **모든 장비에 소실의 저주**가 붙어 있습니다.

- 다이아몬드 검 — 날카로움 V, 내구성 III
- 다이아몬드 도끼 — 날카로움 V, 내구성 III
- 다이아몬드 곡괭이 — 효율 V, 내구성 III
- 다이아몬드 투구 / 흉갑 / 각반 / 부츠 — 보호 IV, 내구성 III
- 방패 — 내구성 III

## 설치

1. `pack` 폴더를 통째로 압축하거나, 함께 들어 있는 `pvp_essential.zip` 을 사용합니다.
2. 서버의 `<월드 이름>/datapacks/` 폴더에 넣습니다.
   ```
   server/
     world/
       datapacks/
         pvp_essential.zip      ← 또는 pack 폴더를 복사한 pvp_essential/
   ```
3. 서버를 재시작하거나 `/reload` 를 실행합니다.
4. `/datapack list` 에 `file/pvp_essential` 이 보이면 적용된 것입니다.

> 서버 전체(모든 월드)에 적용하려면 `server.properties` 의 `initial-enabled-packs` 대신
> 각 월드의 `datapacks` 폴더에 넣는 방식을 권장합니다.

## 동작 방식 (관리자용)

### 폭발 피해 0 (크리스탈·정박기만)

크리스탈 폭발은 TNT·크리퍼와 데미지 타입이 `minecraft:explosion` 으로 완전히 같아서,
데미지 타입만으로는 구분할 수 없습니다. 그래서 **폭발원 근처에 있을 때만** 무효화합니다.

1. 데미지 타입 태그 `#minecraft:bypasses_resistance` 에 **폭발 3종을 제외한 모든 바닐라 데미지 타입**을 추가합니다.
   → 저항 효과가 **폭발 피해에만** 작용하게 되고, 칼·화살·낙하·불 등은 바닐라와 100% 동일합니다.
2. 매 틱, **엔더 크리스탈 엔티티 16칸 이내**의 플레이어에게만 보이지 않는 저항 V 를 3초씩 부여합니다.
   크리스탈을 놓는 순간(같은 틱에 바로 터뜨리는 경우)에도 어드밴스먼트로 즉시 부여합니다.
3. **리스폰 정박기**는 블록이라 매 틱 탐색이 불가능하므로, 글로우스톤으로 충전하는 순간
   시선 방향 레이캐스트로 정박기 위치를 찾아 마커를 남겨 두고, 그 마커 주변에 같은 방식으로 저항을 부여합니다.
   정박기 블록이 사라지면 마커도 자동으로 정리됩니다.

결과: **크리스탈·정박기 폭발 피해 0, TNT·크리퍼·침대 폭발은 바닐라 그대로**. 넉백은 모두 유지됩니다.

- 부수 효과 1: **저항 물약 / 거북 마스터 물약 / 신호기 저항 효과가 폭발 외에는 무의미**해집니다 (1번 태그 때문).
- 부수 효과 2: 크리스탈·정박기 **바로 옆(16칸)에서 터진 TNT** 도 함께 무효화되고, 크리스탈이 사라진 뒤
  **약 3초 동안** 보호가 남습니다.
- 데이터팩을 넣기 **전에 이미 충전되어 있던 정박기**는 마커가 없어 무효화되지 않습니다.
  (한 번 더 충전하면 그때 마커가 생깁니다.)
- 모든 폭발을 0 으로 만들고 싶다면 `function/slow_tick.mcfunction` 에
  `execute as @a run effect give @s minecraft:resistance infinite 4 true` 한 줄을 추가하면 됩니다.
- 되돌리려면 `data/minecraft/tags/damage_type/bypasses_resistance.json` 을 지우면 됩니다.
- 앞으로 마인크래프트에 **새로운 데미지 타입이 추가되면** 위 태그 파일에 한 줄 추가해야 합니다.
  (추가하지 않으면 크리스탈 근처에서 그 피해만 0 이 됩니다.)

### 철퇴 쿨타임
내려찍기 명중을 감지하면 철퇴를 30초 동안 **겉모습·내구도·인챈트·공격력이 동일한 임시 아이템**으로 바꿉니다.
철퇴가 아니게 되므로 내려찍기만 막히고, 일반 근접 공격 성능은 그대로입니다.
쿨타임이 끝나면 완전히 동일한 철퇴로 복구됩니다. (서버가 꺼져도 재접속 시 자동 복구)

### 겉날개 / 급류 / lunge
- 겉날개: `minecraft:glider` 컴포넌트만 잠시 제거 (아이템 자체는 그대로)
- 급류 삼지창: 급류 인챈트만 잠시 제거 (레벨은 저장했다가 그대로 복구)
- 창 lunge: lunge 인챈트만 잠시 제거

### 전투 로그아웃
`leave_game` 통계로 재접속을 감지하고, 전투 점수가 남아 있으면 접속 2초 뒤에 사망 처리합니다.
처벌을 피하려고 곧바로 다시 나가도 예약은 유지됩니다.
**서버가 재시작된 직후 60초 동안은 처벌하지 않습니다** (서버 다운으로 튕긴 사람 보호).

## 알려진 제한

- **창 lunge 쿨타임**은 lunge 찌르기가 **대상에 명중했을 때** 시작됩니다. 허공에 휘두른 lunge 는 감지되지 않습니다.
  (바닐라 데이터팩이 제공하는 감지 수단이 "공격 명중" 뿐입니다.)
- 폭발 무효화는 크리스탈 16칸 이내 / 충전된 정박기 주변에서만 작동합니다 (위 설명 참고).
- 저항 효과가 폭발 피해에만 작용하게 되므로 저항 물약·신호기 저항이 사실상 무의미해집니다.
- 철퇴 쿨타임 중인 철퇴에 별도의 커스텀 속성(공격력 수정 등)이 붙어 있었다면 복구 시 바닐라 기본값으로 돌아옵니다.
- 엔더 상자 안의 엔더 진주·토템은 개수 제한 대상이 아닙니다.

## 버전 호환

- `pack.mcmeta` 는 구버전용 `pack_format`/`supported_formats` 와 신버전용 `min_format`/`max_format` 을 모두 담고 있습니다.
- 26.2 에서 엔티티 조건 문법이 바뀌었기 때문에, 해당 버전용 파일은 `v26_2` 오버레이 폴더에 따로 들어 있고
  포맷 107 이상에서만 자동으로 사용됩니다. 그 이하 버전은 기본 폴더의 파일을 사용합니다.
- 창(spear)·lunge 관련 파일은 창이 없는 버전에서는 조용히 무시되도록 선택적(`required: false`) 태그로 참조합니다.
