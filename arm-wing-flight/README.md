# 팔 벌려 비행 (Arm Wing Flight)

웹캠 앞에서 **두 팔을 벌리면 그게 날개가 된다.** 상반신 포즈를 실시간으로 읽어
도시 상공을 나는 비행기를 조종하는, 세로 화면 웹 게임이다.

화면은 숏폼 영상처럼 위아래로 나뉜다.

```
┌───────────────────────────┐
│  웹캠 + 라임색 팔 스켈레톤   │  ← 어깨·팔꿈치·손목만 추적
├───────────────────────────┤  ← 체력 게이지
│                           │
│   3D 도시 · 비행 · HUD     │  ← 고도 / 비행 거리 / 생존 시간
│                           │
└───────────────────────────┘
```

## 조작

| 동작 | 결과 |
| --- | --- |
| 양팔을 활짝 벌린다 | 양력 발생 — 상승 |
| 한쪽 팔을 내린다 | 그쪽으로 선회 (기체도 같이 기운다) |
| 두 손을 어깨 위로 올린다 | 기수 상승 |
| 팔을 아래로 힘껏 내리친다 | 날갯짓 부스트 — 순간 가속 |
| 팔을 내리고 있는다 | 활공 + 체력 회복 |

체력 게이지는 팔을 벌리고 있는 동안 계속 닳는다. 다 닳으면 양력이 절반 아래로
떨어져 가라앉으므로, **벌렸다 내렸다**를 반복하며 고도를 관리해야 한다.
건물이나 지면에 닿으면 끝. 최고 비행 거리는 `localStorage`에 남는다.

카메라를 못 쓰는 환경이라면 시작 화면에서 **키보드로 하기**를 고르면 된다.
`Space` 날개 펴기 · `←` `→` 선회 · `↑` `↓` 기수 · `Shift` 날갯짓.

## 실행

정적 파일이라 빌드가 없다. 다만 ES 모듈과 `getUserMedia`를 쓰므로
`file://` 이 아니라 로컬 서버로 열어야 한다.

```bash
cd arm-wing-flight
python3 -m http.server 8765
# http://localhost:8765
```

카메라 권한은 `localhost` 또는 HTTPS에서만 허용된다는 점에 주의.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 세로 9:16 무대, 카메라 패널 / 게임 패널 / 오버레이 |
| `styles.css` | 레이아웃과 HUD. 글자 크기는 `cqw`로 무대 폭에 맞춰 커진다 |
| `src/pose.js` | MediaPipe Pose → `{ lift, turn, pitch, flap }` 변환 + 스켈레톤 렌더 |
| `src/game.js` | three.js 씬, 비행 물리, 무한 도시 생성/재활용, 충돌 |
| `src/hud.js` | 체력 바 · 고도계 · 거리/시간 · 큰 자막 |
| `src/main.js` | 화면 전환, 메인 루프, 키보드 대체 조작 |

포즈 모듈은 **카메라를 켤 때만 동적으로 import** 한다. MediaPipe를 못 받아오는
환경에서도 키보드 모드는 그대로 돌아간다.

### 포즈에서 조종값을 뽑는 방법

모든 값은 어깨너비로 나눠 정규화하므로 카메라와의 거리에 영향을 받지 않는다.

- **양력** — 두 손목의 가로 간격 / 어깨너비. 팔을 내리면 약 1.2, T자 자세면 약 3.0.
- **선회** — 화면 기준 왼손과 오른손의 높이 차. 화면이 거울이므로 이미지 x가 큰
  쪽이 "화면 왼손"이다.
- **기수** — 어깨 중심과 손목 중심의 높이 차.
- **날갯짓** — 손목 중심이 아래로 내려가는 속도. 짧게 붙었다 사라지는 임펄스.

여섯 개 랜드마크(양 어깨·팔꿈치·손목)의 신뢰도가 떨어지면 추적을 끊고 입력을
서서히 0으로 놓아준다. 인식이 잠깐 흔들렸다고 곧장 추락하지 않게 하기 위해서다.

## 외부 의존성

CDN에서 직접 가져오며 번들러가 없다.

- [three.js](https://threejs.org) `0.160.0` — 3D 렌더링
- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe) `0.10.14` + `pose_landmarker_lite` — 포즈 추적
- [Pretendard](https://github.com/orioncactus/pretendard) — 한글 폰트

포즈 추론과 렌더링은 전부 브라우저 안에서 끝난다. 영상이 서버로 나가는 일은 없다.
