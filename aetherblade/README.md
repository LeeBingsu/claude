# AETHER BLADE · 에테르 블레이드

three.js 로 만든 브라우저 3D 액션 RPG. 별도 서버·빌드 없이 정적 파일로 동작한다.
`index.html` 을 정적 서버로 열면 바로 실행된다 (`python3 -m http.server` 등).

## 특징
- **플레이어블 3인** — 염화 대검 리엔 / 빙결 쌍검 세라 / 뇌전 장창 카이, 실시간 전환
- **원소 반응** — 융해 · 과부하 · 초전도 · 균열 파열
- **몬스터 6종 + 3페이즈 보스**, AI 상태기계
- **임무 5장** — 컷신·대사·레벨업·전리품으로 이어지는 스토리
- **연출** — 시네마틱 카메라, 무기 궤적, 히트스톱, 화면 흔들림, 잔상
- **오디오** — WebAudio 로 즉석 합성한 효과음 + 탐험/보스전 BGM (외부 음원 없음)
- **모바일** — 가상 스틱·터치 시점, 품질 자동 조절
- **전용 무기** — 「빙화 낙월」(오리지널 글레이브) 장착 옵션

지형·캐릭터·몬스터·텍스처·효과음·배경음까지 전부 코드로 생성하며, 외부 에셋 파일을 쓰지 않는다.
(예외: `vendor/three.min.js` — three.js r147, MIT.)

## 커스텀 캐릭터 모델 (선택)
타이틀 → "커스텀 모델" 에서 본인이 가진 `.pmx`/모델 `.zip` 을 드롭하면 플레이어 캐릭터가 그 모델로 바뀐다.
여러 벌을 넣으면 의상(스킨)으로 등록되어 게임 안에서 갈아입을 수 있다.

- 파일은 **브라우저 밖으로 나가지 않는다** — 서버 업로드 없이 전부 클라이언트에서 처리하고,
  저장을 켜면 이 기기의 IndexedDB 에만 남는다.
- **모델 파일은 이 저장소에 포함하지 않는다.** 많은 배포 모델(예: KURO GAMES 계열)이
  재배포·개조·R18 이용을 금지하므로, 본인이 정식으로 받아 둔 파일만 개인 용도로 사용할 것.

## 조작
WASD 이동 · 마우스 시점 · 좌클릭/J 공격 · E 스킬 · Q 궁극기 · Shift 질주(짧게 눌러 회피) ·
Space 점프 · F 상호작용 · R 회복약 · V 락온 · 1/2/3 캐릭터 전환 · Tab 임무 기록 · Esc 메뉴.
모바일은 왼쪽 드래그 이동 / 오른쪽 드래그 시점 + 화면 버튼.
