    전투 팁

    속성이 다른 캐릭터로 번갈아 때리면 원소 반응이 터진다 — 빙결→염화 융해(×2), 염화→뇌전 과부하(폭발), 빙결→뇌전 초전도(방어↓). 붉은 부채꼴이 뜨면 적의 공격 예고다. 대시로 빠져나가면 무적 판정이 붙는다.

    커스텀 캐릭터 모델 (MMD · PMX)

    가지고 있는 .pmx 또는 모델 .zip 을 아래에 끌어다 놓으면 플레이어블 캐릭터의 몸이 그 모델로 바뀐다. 게임의 절차적 애니메이션(달리기·콤보·회피·궁극기)이 PMX 스켈레톤에 그대로 적용된다.

    zip 또는 .pmx 를 여기에 놓기 또는 눌러서 파일 선택 · 여러 개 한 번에 가능
    의상 · 스킨
    파일을 추가로 넣으면 의상으로 등록된다. 눌러서 갈아입기.

    모델을 기다리는 중.

    파일은 이 브라우저 밖으로 나가지 않는다 — 서버 업로드 없이 전부 로컬에서 처리하고, 저장을 켜면 이 기기의 IndexedDB 에만 남는다. 모델 파일은 이 저장소에 포함되어 있지 않다. 원작자가 재배포를 금지한 모델이 많으니, 본인이 정식으로 받아 둔 파일만 개인 용도로 사용할 것.

    AETHER BLADE

    three.js 로 만든 브라우저 3D 액션 RPG. 지형·캐릭터·몬스터·텍스처·효과음·배경음까지 전부 코드로 즉석 생성하며, 외부 에셋 파일을 쓰지 않는다.

    • 플레이어블 3인 — 염화 대검 리엔 / 빙결 쌍검 세라 / 뇌전 장창 카이. 실시간 전환
    • 원소 반응 — 융해 · 과부하 · 초전도 · 균열 파열
    • 몬스터 6종 — 늑대, 우두머리, 허물 병사, 근위병, 균열 술사, 그리고 3페이즈 보스
    • 임무 5장 — 컷신과 대사로 이어지는 스토리 · 레벨업 · 전리품
    • 연출 — 시네마틱 카메라, 무기 궤적, 히트스톱, 화면 흔들림, 잔상
    • 모바일 — 가상 스틱 · 터치 시점 · 품질 자동 조절

    수위: 스타일화된 액션 폭력(15세 이용가 수준). 선혈·잔혹 묘사는 넣지 않았다.
