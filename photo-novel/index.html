1 Gemini 설정

키 발급받기 ↗

키는 이 브라우저에만 남고, 요청은 브라우저에서 구글 서버로 바로 갑니다. 중간 서버가 없습니다.

키를 넣고 목록 불러오기를 누르면 계정에서 쓸 수 있는 모델이 채워집니다.

문체·시점·인물 설정·금지사항 등 원하는 것을 자유롭게 적으세요. 매 요청에 그대로 전달됩니다.

AI 티 빼기 (imnotai.kr)

쓴 글을 imnotai.kr 의 한국어 윤문에 넣어 AI 티를 뺍니다. 그 API 는 자기 웹앱용이라 다른 사이트에서 바로 부를 수 없어(CORS), 직접 띄운 중계(프록시) 주소가 있어야 합니다. 비워 두면 이 기능은 꺼집니다.

{url} 을 넣으면 그 자리에 대상 주소가 들어갑니다. …/?url= 로 끝나면 뒤에 붙이고, / 로 끝나면 주소를 그대로 이어 붙입니다. 그 외에는 적어 준 주소로 그대로 보냅니다.

자동은 대목·단편이 하나 끝날 때마다 이어서 돌립니다.

백업 (파일로)

작업은 이 브라우저 안에 저장되지만, 브라우저 데이터가 지워지면 함께 사라집니다. 백업 파일에는 사진 원본과 글이 모두 들어 있어서, 폰에서 사진을 지워도 이 파일 하나로 그대로 되살리고 그림 저장·글 추가를 계속할 수 있습니다.

연작·단편 쓰기가 끝나면 백업 zip 이 다운로드 폴더에 저장됩니다. 처음 한 번은 브라우저가 "여러 파일 다운로드" 허용을 물을 수 있습니다.

위의 자동 저장은 사진과 글을 나눠 담고, 이 사본은 프로젝트 전체를 zip 하나로 별도 저장소에 한 번 더 둡니다. 기본 저장소를 못 읽거나 비어 있으면 열 때 이 사본에서 자동으로 되살립니다. 둘 다 이 브라우저 안에 있어서, 브라우저의 "사이트 데이터 삭제"를 하면 함께 사라집니다 — 그럴 때를 위해 아래 파일 백업이 있습니다. API 키는 보안상 사본에 넣지 않습니다(이 브라우저에 저장 체크를 하면 따로 남습니다).

맞춤 지시사항(연작·단편), 모델, 모든 옵션, 번역·AI 티 빼기·그림 설정, 테마와 글자 크기를 JSON 하나로 담습니다. 사진과 글은 들어가지 않습니다. API 키를 넣었다면 그 파일은 남과 공유하지 마세요.

고급 옵션

모델이 거부하면 한 단계씩 자동으로 내려가며 다시 시도합니다.

"정책상 거부", 안전 필터, 빈 응답으로 끝난 대목에 해당합니다. "될 때까지" 는 중단을 누를 때까지 같은 자리에서 계속 씁니다. 설정값(temperature 등)은 그대로 두고, 다른 문장으로 써 달라고만 덧붙입니다.

구간마다 무슨 일이 있었는지(줄거리 한 줄)와 인물·장소·문체를 쌓아 두고 매 요청에 함께 보냅니다.

줄거리 한 줄은 늘 받고, 설정은 이 주기로만 갱신합니다.

0 이면 원본 그대로 보냅니다. 줄이면 토큰과 업로드 시간이 줄어듭니다.
