# photo-novel

현황·기능·코드 지도·관례는 한 파일에 모아 두었습니다. 먼저 읽으세요.

@AGENTS.md

작업할 때 특히 지킬 것 (자세한 이유는 위 파일의 7·8절):

- 번들러·CDN·외부 라이브러리를 쓰지 않습니다. UI 문구와 주석은 한국어입니다.
- 코드를 바꾸기 전후로 `node photo-novel/test/run-tests.js` 를 돌립니다.
- API 키가 파일·zip·로그·커밋에 들어가지 않게 합니다. 사용자 작업을 덮어쓰지 않습니다.
- 기능·저장 형식·설정 칸을 바꾸면 `AGENTS.md`(와 사용자용 `README.md`)도 같이 고칩니다.
