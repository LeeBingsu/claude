# photo-novel — 프로젝트 현황과 지도

> 사람과 개발 도구(Claude Code, Codex, Cursor 등)가 **이 파일 하나로** 무엇이 있고 어디까지 됐는지, 어디를 고치면 되는지 파악하도록 쓴 문서입니다.
> 사용자용 설명은 `README.md`, 폰트 라이선스는 `fonts/LICENSES.md`. 기능을 바꾸면 **이 파일도 같이 고치세요**(끝의 "유지 규칙").
> 마지막 갱신: 2026-09-29 (PR #40 머지 직후, 단위 테스트 98건).

## 1. 한 줄 요약

사진을 올리면 **Gemini** 가 글을 써 주는 **정적 웹앱**. 빌드 도구·서버·계정·CDN 없음. UI 는 **한국어**.
세 탭: **연작 소설**(사진 사이를 이어 한 편) · **한 장씩 단편**(사진마다 따로) · **만화**(사진 = 컷, 대사를 말풍선으로 얹기).

- 배포: GitHub Pages, 개인 도메인 `opus.kro.kr` (저장소 루트 `CNAME`) → `http://opus.kro.kr/photo-novel/`. **main 에 머지되면 반영**됩니다. (이 저장소의 다른 폴더 `Lyric Kinetics`, `arm-wing-flight`, `daily-integral` 은 별개 프로젝트라 이 문서와 무관합니다.)
- 스택: ES 모듈(`<script type="module">`), 바닐라 JS/CSS, 라이브러리 0개. zip 도 직접 구현(`lib/zip.js`).
- 외부로 나가는 요청: `generativelanguage.googleapis.com`(Gemini) + 사용자가 켠 경우에만 번역 API·AI 티 빼기 프록시. 사진과 API 키는 그 밖으로 나가지 않음.
- 저장소 주소가 `http://` 라 **보안 컨텍스트가 아님** — `navigator.storage.persist()`, Cache Storage 등을 못 씀(코드가 알아서 건너뜀).

**모두 구현·머지됨** (PR #31–#40 및 그 이전). 미완성 기능은 없음.

| 만화 (시나리오 → 대사 → 말풍선, **사진을 터치해 위치 지정**, 모양/색/글꼴 편집, 컷별·전체·세로 이어 저장) | 완료 |
| 검열·거부·빈 응답 재시도, 안전 옵션 단계적 완화, 오프라인 대기, 화면 꺼짐 방지, 다시 열면 이어 쓰기 | 완료 |

| AI 티 빼기 (imnotai.kr, 사용자가 띄운 CORS 프록시 필요) | 완료 (프록시 주소를 비우면 꺼짐) |
| 무료 번역(LibreTranslate → MyMemory 폴백, 키 불필요) | 완료 |
| 글꼴: 눈누 "무료 상용 폰트" 11종 + 글꼴 세트 4종 | 완료. **3종은 저장소에 못 담아 사용자가 파일을 올려야 함**(아래) |
| 화면 글자 크기(70–200%), 라이트/다크 테마, 푸터 "made by Rinple" | 완료 |

**알려진 한계 / 후속 후보**
- **KoPub 바탕·KoPub 돋움·미원체**는 재배포 금지라 미포함. 공식 파일을 "글꼴 파일 올리기"로 올리면 파일명(`kopub…batang|dotum`, `miwon|미원`)으로 알아보고 그 자리에 쓰임(`ownFontFor`). 올리기 전에는 각각 리디바탕 / 나눔스퀘어 네오 / 나눔스퀘어 네오 Heavy 로 보임.
- 나눔손글씨 두 종은 한글 전체를 담아 파일이 각 2.7MB(첫 사용 때 잠깐 걸림). 한자·일본어 한자는 글꼴에 없어 기기 글꼴로 대체.
- 브라우저 사본은 사진이 250MB 를 넘으면 만들지 않음(파일 백업 사용). "사이트 데이터 삭제"를 하면 자동 저장과 사본이 **함께** 사라짐 → 파일 백업이 마지막 방어선.
- **브라우저 E2E 테스트는 저장소에 없음.** CI 는 node 단위 테스트만 돈다(아래 6절). Playwright 로 모의 Gemini 를 붙인 임시 스크립트로 확인해 왔음.
- 만화 대사 생성은 모델에게 위치를 요구하지 않음(위치는 항상 사용자가 터치로 지정).
- AI 티 빼기·번역 공개 서버는 남의 서비스라 언제든 막힐 수 있음(실패해도 원문은 지우지 않도록 되어 있음).

## 3. 기능 지도 (어디서 무엇을 하나)

**연작 탭** — 사진 정렬(이름순·드래그·▲▼) → 구간마다 요청 1회: `직전 사진 + 다음 사진 + 지금까지 줄거리 + 바로 앞 본문`을 보내 "다음 사진의 순간에 도착하며 끝내라"고 지시. 도입부/마무리 옵션, 메모(줄거리) 모드, 문맥 길이 자르기.

**단편 탭** — 사진 1장 = 요청 1회. 분량·형식은 전부 사용자 지시사항이 결정. 언어별 `texts`(원문·번역) 저장, 한 번 옮기면 재요청 없음. 그림 저장은 **줄이기 전 원본** 위에 글을 굽는다(`lib/poster.js`).

**만화 탭** — 컷마다 시나리오(+등장인물·앞 컷 맥락) → 모델이 `[{speaker,type,text}]` JSON 반환 → 말풍선이 **미배치** 상태로 생성 → 사진 터치로 놓기(누른 채 끌면 꼬리 방향) → 편집(모양 7종·색·글꼴·크기·굵게/기울임·정렬·자동 줄임) → 저장.
- 좌표는 전부 **이미지 대비 비율**(x,w는 너비 / y,h는 높이 / 글자 크기·테두리는 너비). 미리보기와 저장이 같은 그리기 코드를 씀(저장은 `image.original || image.blob`).
- `placed:false` 말풍선은 그려지지도, 저장 그림에 들어가지도 않음(`.txt` 대사에는 포함).
- 말풍선 종류 `say|think|shout|whisper|narration` 마다 기본 모양·글꼴이 정해져 있음(`TYPE_STYLE`, `FONT_SETS`). 외침은 굵게+기울임.

**공통** — 모델 설정(키·모델·temperature…)은 세 탭이 공유, **맞춤 지시사항은 탭마다 따로**. 마지막 탭·접힘 상태·글자 크기·테마를 기억.

## 5. 데이터와 저장

| 무엇 | 어디 | 비고 |
| --- | --- | --- |
| 모든 옵션·지시사항·테마·글자 크기 | `localStorage['photoNovel.settings.v1']` | 필드 목록은 `app.js` 의 `FIELDS` — 새 설정 칸은 여기에 추가해야 저장·설정 JSON 에 실린다 |
| API 키 | `localStorage['photoNovel.apiKey.v1']` | "이 브라우저에 저장"을 켠 때만. **zip·사본·백업에는 절대 안 들어감**, 설정 JSON 에는 옵션(기본 켜짐)으로만 |
| 사진 Blob·본문·순서·메모·단편·만화(말풍선·업로드 글꼴) | IndexedDB `photoNovel` (`images`: `font:<이름>` 행 포함, `meta.comic {order,items,fonts}`) | 복원이 끝나기 전엔 저장 안 함(`restoreState: pending|ok|failed`) |
| 위 전부의 zip 한 벌 | IndexedDB `photoNovelMirror` (+ https 면 Cache Storage) | 변경 15초 뒤 디바운스, 250MB 상한, 기본 저장소가 비면 자동 복원, "지우기" 시 함께 삭제 |
| 파일 백업 / 전체 내보내기 zip | 사용자가 받는 파일 | 같은 형식 |

**프로젝트 zip 형식**: `photo-novel.json`(매니페스트) + `images/` `shorts/` `comic/` `fonts/` + `story.txt` `comic.txt` … 사진은 바이너리 그대로. 연작·단편은 **원본(`original`)** 을 우선 담고, 불러올 때 현재 설정에 맞춰 보낼 크기를 다시 만든다.

**말풍선 데이터** (`normalizeBubble` 이 유일한 입구 — 저장·불러오기·화면 생성 모두 통과):
`{id,type,shape,text,speaker,x,y,w,h,tail:{on,x,y},placed,fill,fillAlpha,stroke,strokeW,color,font,fs,bold,italic,align,autoFit}`.
`font` 는 프리셋 키(`ridi`, `dohyeon`…)이거나 사용자가 올린 글꼴 이름. 옛 키(`gothic`,`serif`,`hand`…)는 `presetKey()` 가 새 키로 옮긴다.

## 6. 개발 방법

```bash
node photo-novel/test/run-tests.js        # 단위 테스트 (98건, 몇 초)
cd photo-novel && python3 -m http.server 8000   # 실행 (file:// 은 모듈/CORS 제약)
```
- ES 모듈 문법 확인: `.js` 를 `.mjs` 로 복사해 `node --check`.
- 브라우저 확인은 Playwright(크로미움 `/opt/pw-browsers/...`) + `generativelanguage.googleapis.com/**` 를 `route` 로 가로채 모의 응답(SSE `data: {...}`)을 주는 방식으로 해 왔다. 터치 배치는 CDP `Input.dispatchTouchEvent` 로 검증.
- 새 로직은 가능하면 **DOM 없는 순수 함수**로 `lib/` 에 두고 `run-tests.js` 에 검사를 추가한다(만화 좌표·글꼴 매핑·줄바꿈·zip·저장 형식이 모두 그렇게 되어 있음).

## 7. 관례 (지켜 주세요)

1. **번들러·CDN·외부 라이브러리 금지.** 파일 그대로 열려야 한다. 글꼴도 `fonts/` 에서만 (`@font-face` 는 그 글꼴로 그릴 때만 내려받음).
2. UI 문구·주석·커밋 설명은 **한국어**(커밋 제목은 영어여도 됨). 주석은 "왜"를 적는 짧은 한국어.
3. 색은 `:root` 토큰, 다크 모드 대응(`prefers-color-scheme` + `data-theme`). 폰(좁은 폭)에서 먼저 확인.
4. **API 키를 파일·zip·로그·커밋에 넣지 않는다.** 새 저장 경로를 만들 때 키가 섞이지 않는지 확인.
5. **사용자 작업을 덮어쓰지 않는다.** 복원 전 저장 금지, 지우기는 사본까지, 실패한 대목은 원문 보존, 쓰다 만(busy) 것은 저장 안 함.
6. **글꼴 추가 시 라이선스를 먼저 확인**(재배포·웹폰트 임베딩·수정 가능 여부). 가족 이름은 `"PN <이름>"` 접두어를 붙인다 — 화면 글꼴 스택의 같은 이름(예: "Noto Sans KR")과 겹치면 쓰지도 않는 글꼴을 접속마다 내려받게 된다.
7. 새 설정 칸 → `FIELDS` 에 등록(설정 JSON 은 `FIELDS` 값을 그대로 담으므로 `settings-file.js` 는 고칠 일이 없다) + `README.md` 표 갱신.

## 8. 함정 (실제로 겪은 것)

- **캔버스는 CSS 글꼴을 저절로 불러오지 않는다.** 그리기 전에 `loadFonts()`(= `document.fonts.load`) 를 기다려야 한다. 안 그러면 첫 그림이 대체 글꼴로 나온다.
- 폰 갤러리 `File` 참조는 사진을 지우면 못 읽는다 → 올릴 때 **바이트를 복사**(`ownCopy`). Blob 만 저장.
- 지운 작업이 탭을 닫을 때 되살아난 적 있음 → `saveDirty` 플래그(바꾸기 전에는 pagehide 에서 다시 저장 안 함). 저장/복원 로직을 만질 때 `restoreState`·`saveDirty` 를 함께 볼 것.
- 미리보기와 저장 그림의 그리기 코드를 갈라놓지 말 것(`drawBubbles` 하나). 말풍선은 오프스크린 캔버스에 몸통+꼬리를 하나의 Path 로 그려 테두리가 이음새 없이 이어진다.
- 줄 첫머리에 `?` `.` 닫는 따옴표가 홀로 오면 안 됨 → `wrapLines` 금칙 규칙. 손대면 `run-tests.js` 의 줄바꿈 검사를 돌릴 것.
- 터치로 끌 때 화면이 같이 스크롤되면 안 됨 → 끄는 동안에만 `touchmove` 를 `preventDefault`(비수동 리스너, `app.js` 컷 편집의 `bindCanvas`). 사진 옆 여백을 잡고 스크롤.
- 선택 상자(`<select>`)의 값이 옵션 목록에 없으면 조용히 첫 항목으로 돌아간다 — 글꼴 세트 이름을 바꿀 때 저장된 옛 값이 어떻게 되는지 확인(`fontSetFor` 는 모르는 세트를 기본으로 돌림).
- 브라우저 저장소는 **사이트 주소마다 따로**다. 주소(`http`↔`https`, 도메인)가 바뀌면 이전 작업이 안 보인다.
